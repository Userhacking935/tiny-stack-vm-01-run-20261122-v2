# Tiny stack virtual machine

A from-scratch VM for make.fun's tiny stack ISA v1, written for the [tiny-stack-vm-01-run-20261122](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty. `main.ts` (Node 22, no dependencies) runs every instance in one pass: 32-bit wrapping integers, a 256-value stack, branches, calls, 256 words of memory, input/output, and all ten traps with their exit codes.
